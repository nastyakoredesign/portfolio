About

I'm a product designer who checks her work in code

I'm Nastya, a product designer in Kyiv. I design portals and CRMs for fintech and healthcare, build the design system behind them, and review what developers ship, role by role.

Kyiv, Ukraine · Remote or on-site · In design since 2022 · English B2

My path

From choir conducting to product design

  1. Childhood

    As a kid, I wanted to be an architect. I didn't become one, but I built houses and whole structures in Minecraft's creative mode and even ran a YouTube channel about my builds. Looking back, that's where design started for me.

  2. Choir conducting

    I also sang, and music won: I trained as a choir conductor and taught at a school for a few months. Those months showed me teaching wasn't for me.

  3. Product design

    I was always at home with computers, so I tried design and stayed. I started on Upwork in 2022 with landing pages and online stores, then joined a Canadian eCommerce agency as their second designer. Since 2023, I've designed B2B portals and CRMs for fintech and healthcare at Empeek.

How I work

Spec first, then Figma, then the build

  1. 01

    I start with requirements.

    I break features down with the BA and sketch screens while the spec is still being written, so gaps show up early.

  2. 02

    I design from the system.

    Screens are built from design system components with their states, so developers get parts they already know.

  3. 03

    I show options.

    When the choice isn't obvious, the client compares two or more variants and we pick one together.

  4. 04

    I check the build for every role.

    After each module reaches the dev environment, I compare it with the design and the spec and hand developers a list of mismatches.

Design and code

I don't stop at handoff

On Centology, I've reviewed 16 modules on the dev environment and logged about 1,100 mismatches. To explain them to developers, I learned to read HTML and CSS.

Then I automated the routine. My Claude skill checks the build against Figma and the spec for every role: one entity review went from 10–12 hours to 5–6.

This site is my first project from Figma to code. I designed it, set up the tokens and wrote the specs. Claude Code wrote the HTML, CSS and JS; I read the code and checked every page.

On client products, developers write the code. My part is the design, the system and the review.
